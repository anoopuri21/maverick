# Bachelors LP — Keyword Research (GCC / UAE)
**Project:** Maverick Business Academy — Bachelors Landing Page for GCC/UAE prospects (BBA / BSc / BA (Hons) / Top-up)
**Date:** 2026-09-11 · **Market:** UAE (Dubai · Sharjah · Abu Dhabi) + wider GCC (KSA, Qatar, Oman, Kuwait, Bahrain) + Gulf-based expats (India, Pakistan, Philippines, Egypt)
**Method:** live SERP observation (UAE/GCC undergraduate queries, 2026-09), competitor page audit (campus branch campuses, online agents, fast-track providers), directory data (educations.com: 40 bachelors programmes in Sharjah; bachelorsportal: 400+ UAE bachelor's listings), fee tables published by coursetakers.ae (Apr-2026) and Fateh (Jan-2026). Volumes are directional — re-run in Keyword Planner before paid media.

**Market context (why this set wins):** the bachelors SERP in the UAE is a trust desert. Head-term results are agent/guide content farms (Fateh, AECC, globaltree.in, bradfordia), campus-premium branch campuses (S P Jain, Middlesex, UOWD), and 12-month/1-year "BBA" fast-tracks priced AED 3,500–25,000 (King's, Study Wink, Sama, Tamkeen, Ascencia). Nobody credible offers: **named-award university degrees + online/weekend-friendly delivery + no student visa + a physical Gulf office**. That is the exact gap K1–K8 exploit.

## 4. On-Page Rules (this LP only)
- H1 = benefit-led; the exact K1 phrase lands in the hero subhead (same QA logic as London LP + Masters LP).
- `Dubai` / `Sharjah` / `Abu Dhabi` each named ≥ once in H2s or first-100-words (K1/K5 local SEO); `GCC` in ≥ 2 places; `AED` in the fees section; INR only in a dated parenthetical (K7 rail).
- Every objection long-tail (visa, attestation, recognition, 12-month doubt, parent doubt, working-while-studying) has an FAQ home → FAQPage 1:1.
- No sentence template may repeat verbatim in more than one section (Masters-audit P0 rule — keyword stuffing detector).
- Internal links → `/programs/{slug}` per family, `/global-bachelors-pathway` (Europe rail — "prefer to relocate?"), `/online-mba-masters-uae` (post-bachelors rail, once un-holded), `/accreditations` (if exists), `/pathway-programs`.
- Recognition phrasing is source-dated (MoE July-2023; MOHRE 2026 guidance) and uses the private-sector-safe wording from SOP §3.1 — never "visa guaranteed" / "recognised for all purposes".
- Arabic: do **not** ship a half-translated page. Separate `ar/` build with hreflang = post-launch decision, not v1.
