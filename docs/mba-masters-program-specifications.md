## Publishing rule

This register uses **only** the attached `listing.pdf`.

- Programme names are copied from the PDF.
- University names and programme categories are copied from the PDF.
- The frontend does not add programme, university, duration, fee, entry, assessment, module, accreditation or progression data from any other source.
- The PDF does not contain detailed duration, fee, entry, assessment or module specifications for every programme. Those details are therefore not published in this landing-page catalogue.
- The word **Specifications** on the page refers only to the PDF-backed university/category/page/count record shown separately from the programme list.
