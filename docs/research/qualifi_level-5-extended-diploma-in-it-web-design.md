## 3. ⚠️⚠️ Units as published — WEB DESIGN IS LISTED TWICE

Qualifi's page prints the following twelve bullets, verbatim and in this order:

1. Information Technology and IT Ethics
2. Mathematics and Statistics for IT
3. PC Maintenance and Operating Systems
4. Computer Graphics Editing and Database Concepts
5. **Web Design**
6. Web Programming
7. Technopreneurship
8. Network Security
9. C#.NET Programming
10. System Administration
11. Content Management Systems
12. **Web Design**  ← *same title as item 5*

**This is a genuine error on Qualifi's own page, not a transcription slip.** The title
"Web Design" appears at both position 5 and position 12.

**What the cross-check shows.** Comparing with the generalist award (S.No 39), the
Level 4 web electives are *Web Programming* and *Graphical User Interface (GUI)*, and
the Level 5 web electives are *Content Management Systems* and *Web Design*. On that
basis position 5 should almost certainly be **Graphical User Interface (GUI)**, with
position 12 correctly being Web Design.

**Editorial rule — do NOT silently substitute GUI.** Qualifi has not published that
correction. The page must:
- present the eleven distinct unit titles actually published,
- state openly that the awarding body's list repeats "Web Design" and therefore shows
  eleven distinct subjects where twelve are claimed,
- direct the reader to the Centre Specification as the authority,
- make **no** assertion about what the twelfth unit really is.

→ **GAP-SOURCE-QF-22.** Same family of problem as QF-07 (S.No 32) and QF-14 (S.No 37),
but this one is unambiguous: a literal duplicate.

## 4. Notes

- The web identity comes from Web Design, Web Programming and Content Management
  Systems; the shared eight core units (IT ethics, maths and statistics, PC
  maintenance, graphics and databases, technopreneurship, network security, C#.NET,
  system administration) are common to all four IT awards.
- Content Management Systems is a practical inclusion — most real web work is done in
  one — and is a fair differentiator to highlight.
- As with S.No 40, a reader expecting a pure design course should be told that eight of
  the twelve units are general IT, and that this is not a graphic-design qualification.
