# Faculty Insights — seed images

Is folder me `Faculty Insights.pdf` se nikali hui photos **900 × 990 px JPG** (card ratio 3:3.3) me rakhi jayengi.

## Upload steps (manual, Admin Panel)
1. Filament → **Homepage → Faculty Insights** → faculty row **Edit**
2. **Featured Image** → **Upload New** → yahan ki matching file select karo
3. Save. Mapping neeche:
